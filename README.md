# QR Code Generator

A simple web app that turns any text or URL into a QR code instantly.

🔗 **Live demo:** https://dulcet-kelpie-6bacf3.netlify.app

## Features

- Generate a QR code from any text or link
- Instant preview in the browser
- Input validation: shows an error state when the field is empty
- Responsive, lightweight, no frameworks

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- [QR Server API](https://goqr.me/api/) for generating the QR image
- Deployed on Netlify

## How It Works

1. Type or paste text or a URL into the input box.
2. Click **Generate QR Code**.
3. The app sends your text to the QR Server API and displays the returned image.
